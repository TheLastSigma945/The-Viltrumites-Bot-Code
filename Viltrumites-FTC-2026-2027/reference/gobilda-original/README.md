# Supplied goBILDA Reference

`BioBuzzStarterbotTeleop.java` is the unmodified source file supplied for this project. It is stored outside `TeamCode`, so Gradle does not compile it.

Use it as the hardware-behavior baseline when checking drivetrain directions, servo directions, launcher PIDF/velocity values, and driver controls. The maintained competition code adds structure and safety checks, but intentional behavior changes must have a documented reason.
