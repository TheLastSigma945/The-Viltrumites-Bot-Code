# First Startup Checklist

Use this checklist after wiring changes, configuration changes, or a new software upload. Wear eye protection around the launcher and keep hands, hair, wires, and clothing away from every moving part.

- [ ] **1. Put the robot on stable blocks.** All drive wheels must be clear of the floor. Expected: the robot cannot drive off the work surface when a motor starts.
- [ ] **2. Verify Driver Station connection.** Confirm the Driver Station shows the correct Robot Controller and no version mismatch. Expected: normal connection status and live battery voltage.
- [ ] **2a. Assign both physical controllers.** For Logitech/Xbox-style controllers, press START+A for Gamepad 1 and START+B for Gamepad 2. For PS4-style controllers, use OPTIONS+Cross and OPTIONS+Circle. Expected: each controller icon appears over the correct Driver Station user and highlights green when a control moves.
- [ ] **2b. Verify TeleOp gamepad telemetry.** Initialize `Viltrumites TeleOp` before PLAY. Expected: `Gamepad 1 status: ASSIGNED` and `Gamepad 2 status: ASSIGNED`. If either controller was unplugged, reconnect and assign it again.
- [ ] **3. Run `StarterBot Hardware Test`.** Press INIT and read all telemetry before START. Expected: `Hardware Initialization: OK`. If not, stop and fix the exact listed hardware name/type.
- [ ] **4. Test each drivetrain motor individually.** Select `FRONT_LEFT_DRIVE`, `FRONT_RIGHT_DRIVE`, `LEFT_DRIVE`, and `RIGHT_DRIVE` in turn; hold A briefly and release. Expected: only the selected wheel moves. The front-left power command is reduced because its motor is rated 1150 RPM.
- [ ] **5. Confirm software direction.** Each positive wheel command must roll the robot forward. Left wheels start at software `FORWARD`; right wheels start at `REVERSE`. Fix any wrong wheel direction before testing mecanum mixing.
- [ ] **6. Test low-power forward.** Hold D-pad up. Expected: all four wheels roll forward, then stop on release.
- [ ] **7. Test low-power backward.** Hold D-pad down. Expected: both sides move backward together, then stop on release.
- [ ] **8. Test left turn.** Hold D-pad left. Expected: both left wheels reverse and both right wheels advance.
- [ ] **9. Test right turn.** Hold D-pad right. Expected: left wheels advance and right wheels reverse.
- [ ] **9a. Test strafe on blocks, then on clear floor.** In Drivetrain Direction Test, hold B for right or X for left; in Hardware Test, hold B/Y. The latest correction flips only front-left strafe; the other three wheel commands stay as they were. This is not standard X-mecanum mixing: if the robot rotates or fights itself instead of translating sideways, STOP and inspect wheel mounting, motor directions, and wiring before proceeding.
- [ ] **10. Put the robot on the floor in a clear area.** Turn the robot off before lowering it. Expected: at least several feet of clear space and a driver ready to press STOP.
- [ ] **11. Test slow mode.** Run `Viltrumites TeleOp`, hold Y, and use small stick inputs. Expected: correct forward/back/turn behavior limited to 40% command.
- [ ] **12. Test normal driving.** Release Y and gradually test left-stick forward/back and side-to-side, then right-stick turns. Expected: smooth response, no motion inside the joystick deadband, and no motor fighting. Tune `FRONT_LEFT_POWER_SCALE` only after comparing real loaded wheel motion.
- [ ] **13. Test intake with Gamepad 1.** Return to blocks if needed. In Hardware Test, check the motor and both CR servos separately; then in TeleOp gently use the right trigger. Expected: the motor and both corrected side-intake servos pull pieces inward. The left trigger must eject, and reverse must win if both triggers are pressed.
- [ ] **14. Test the arm servo before installing its horn.** Configure Expansion Hub 2 Servo Port 0 as continuous-rotation servo `arm_servo`, leave the horn/linkage disconnected, select `ARM_SERVO` in Hardware Test, and briefly hold A then X. Expected: the servo spins in both directions only while a button is held and stops immediately when released.
- [ ] **15. Test the installed arm with Gamepad 1.** After confirming safe linkage travel, hold the left bumper briefly, release it, then hold the right bumper briefly. Expected: left bumper moves the arm up, right bumper moves it down, and releasing both stops the servo. If reversed, change the configured software direction—not the power wiring.
- [ ] **16. Test windmill with Gamepad 2.** With the launcher off and mechanism empty, move the left stick slowly right and left, then hold one D-pad direction. Expected: the stick gives proportional movement; D-pad left/right gives continuous full-power movement for as long as it is held; releasing the control stops the windmill. If it stops at the same physical angle while telemetry still shows a full command, stop and inspect for a mechanical hard stop, binding, power loss, or the wrong servo type.
- [ ] **17. Test the new 6000-RPM launcher with Gamepad 2.** Clear people and game pieces from the path, put the robot on blocks, and use eye protection. Run the reduced-speed 600-ticks/s hardware test first and check measured velocity. In TeleOp, NORMAL starts at ±1250 ticks/s full trigger. Press PS4 Cross/X to select the previously tested FAST ±2000-ticks/s target; press Circle/O to return to NORMAL. The buttons must not start the motor without a trigger. Test each target gradually, release the trigger, then cautiously test reverse. Equal trigger presses cancel to zero; the windmill and intake stay independent. Do not shoot until direction and trajectory are physically validated.
- [ ] **18. Test full TeleOp only after every previous item passes.** Connect both controllers. Expected: Gamepad 1 exclusively drives and operates the intake and arm; Gamepad 2 independently operates the windmill and launcher; no mechanism starts automatically.
- [ ] **19. Configure and test the optional webcam.** In the active `GojoBot` configuration, run Scan and add the USB camera as `Webcam 1`. Initialize `StarterBot Camera Test` and wait for `STREAMING`, then open the Driver Station's three-dot menu and select Camera Stream. Expected: a refreshable Logitech C270 image appears without affecting any robot mechanism.

## Autonomous Calibration

The Blue and Red autonomous OpModes use timed drive and turn commands, four timed windmill feeds, and a running launcher. Test each profile's directions on blocks first, without balls; then use an empty practice field with a clear launch path. Tune the named constants in the corresponding Blue or Red Java file one at a time. A feed pulse does not guarantee one ball fired, and timed motion does not guarantee a field distance or angle.

## Stop Verification

For every OpMode, press STOP while mechanisms are active. Expected: drive motors, intake motor, intake servos, launcher, windmill, and the continuous-rotation arm servo all stop. If any continuously powered mechanism keeps moving, disconnect robot power and do not operate again until the wiring/configuration fault is understood.
